## What this repo is

SocratesAI is a thinking/content project, not a software product. It explores—Socratic-style—the
first principles of enterprise AI transformation and industry intelligentization. The repository is
a mix of Chinese-language essays (Markdown) and a single Python script that renders one of those
essays as a polished PowerPoint deck.
