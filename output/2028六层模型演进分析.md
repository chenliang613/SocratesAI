> 基于 [AI 产业六层模型](../AI_Layout.md)，推演两年后（2026 → 2028）各层**如何守住护城河**、**如何与相邻层产业分工与协作**。
> 全局判断：底层凭物理与生态壁垒「守城」，上层凭场景与知识密度「拓土」；通用能力加速商品化，护城河整体上移，Token 成为贯穿全链的统一量纲。

## 一、演进主线：2026 → 2028 重塑六层的三股力量

通用能力加速商品化，护城河整体上移；产业从「各层独立」走向「跨层编排闭环」。

| 主线 | 关键词 | 内涵 |
| --- | --- | --- |
| 主线一 · 全栈整合 | 巨头跨层 | 谷歌 / 微软 / 亚马逊 / 阿里 跨层自研，降低对单一上游（如英伟达）的依赖，谋求全栈控制力 |
| 主线二 · 量纲统一 | Token / 结果 | 计费向 Token 与业务结果收敛，成本自下而上层层传导，重塑各层利润分配 |
| 主线三 · Agent 粘合 | 重新编排 | MCP / A2A 等协议把六层重新编排成闭环，Agent 成为新的产业「粘合层」与价值战场 |

> **一句话**：底层「守」、上层「拓」，价值从「造模型」向「懂行业 + 控入口」迁移。

## 二、底层守城

### 2.1 能源层 Energy —— 锁电即锁产能

电力是算力规模的硬约束。谁先锁定廉价、稳定、零碳的电，谁就锁定 AI 的产能上限。

| 护城河 · 如何守住 | 产业分工 · 如何协作 |
| --- | --- |
| 长协绿电 + 核电 / SMR：10 年期 PPA 与核电产能先签先得 | 向算力层供「GW 级稳定零碳电」，按容量长协绑定 |
| 选址即壁垒：靠近富余电网节点的土地与并网许可稀缺 | 与算力层协同设计供电 / 散热，应对芯片功率密度↑ |
| 能源—园区一体化自建：直连电源 + 液冷，PUE 逼近 1.1 | 深度绑定云厂（微软-核电、AWS-SMR），共享扩张红利 |
| 电网与监管关系：长期容量协议构成进入门槛 | 提供绿电资质，帮上层满足合规与碳披露 |

> **本质**：把能源做成「可控的基础设施变量」，用长协 + 垂直整合换取算力产能上限。

### 2.2 算力层 Compute —— 从卖芯片到卖「AI 工厂」

壁垒最高、利润最集中的一层。训练芯片维持寡头，推理芯片走向多元。

| 护城河 · 如何守住 | 产业分工 · 如何协作 |
| --- | --- |
| CUDA / 软件生态：开发者迁移成本仍是最深护城河 | 向能源层要稳定大功率，联合设计供电与散热 |
| 先进制程 + HBM 产能：物理稀缺，绑定产能即绑定算力 | 向模型层供训练 / 推理算力，软件栈深度耦合 |
| 系统级整合：从单卡到机柜级互联，卖「AI 工厂」 | 云厂自研芯片（TPU / Trainium / Maia）分流推理需求 |
| 推理经济性：每 Token 成本成为新战场 | 向上提供推理底座，算力成本按 Token 向上传导 |

> **本质**：训练靠生态与制程守寡头，推理靠能效比应对多元竞争与成本下行。

### 2.3 模型层 Model —— 地板抬高，护城河上移

通用能力增速放缓、加速商品化；前沿仍领先半代，但壁垒从「模型本身」转向「分发 + 协议 + 信任」。

| 护城河 · 如何守住 | 产业分工 · 如何协作 |
| --- | --- |
| 前沿代差：闭源靠数据 + 算力 + 对齐持续领先半代 | 向上把「模型 + 工具 + 协议」打包为 Agent 基础设施 |
| 护城河上移：分发渠道 + Agent 协议（MCP）+ 企业信任 | 向下绑定算力（长期算力承诺）与能源 |
| 成本曲线：规模摊薄训练成本，单位智能成本持续下降 | 与数据层经 RAG / 微调接入企业私域数据 |
| 安全与合规对齐：强监管场景的入场资格 | 开源做长尾与本地化，闭源做前沿与高价值场景 |

> **本质**：通用能力商品化倒逼模型厂向上做 Agent、向下锁算力，靠生态而非参数取胜。

## 三、上层拓土

### 3.1 数据平台层 Data —— 语义层成新壁垒

没有统一、可信、带语义的数据，上层智能无从谈起。数据重力 + 语义层构成双重护城河。

| 护城河 · 如何守住 | 产业分工 · 如何协作 |
| --- | --- |
| 数据引力：入湖仓 + 治理后迁移成本极高（数据重力） | 向模型 / Agent 层供「可信、带语义的燃料」，按消费计费 |
| 语义层 / 本体：统一业务语言，是 Agent 可靠决策的前提 | 与模型层共生：私域数据 ↔ 语义增强 互相成就 |
| AI 原生底座：内置向量检索 + 语义层 + Agent 数据接口 | 向应用层提供统一底座，应用专注场景 |
| 治理与合规：权限、血缘、审计是强监管行业入场券 | 向算力层下沉向量检索 / 特征计算，消费推理算力 |

> **本质**：把散落数据变成「Agent 可消费的语义燃料」，用数据重力 + 语义层锁定企业。

### 3.2 Agent 层 Agent —— 入口即护城河

竞争最激烈、价值重新分配的战场。模型厂向上、应用厂向下、平台厂横向，三股力量在此交汇。

| 护城河 · 如何守住 | 产业分工 · 如何协作 |
| --- | --- |
| 入口即护城河：掌握工作流入口即掌握流量 | 向下调用模型（规划）、数据（上下文）、工具（执行） |
| 协议标准（MCP / A2A）：定义互操作标准者掌握生态 | 与应用层分工：应用供领域工具 + SOP，Agent 供编排 |
| 可靠性与护栏：可控、可审计、可回滚是 2B 胜负手 | 成为应用的新运行时，重塑软件交互形态 |
| 多 Agent 编排 + 记忆：跨系统长任务能力形成壁垒 | 按结果 / 算力计费，价值向能交付结果者集中 |

> **本质**：谁掌握 Agent 入口与协议标准，谁就主导 2028 的产业格局与价值分配。

### 3.3 应用层 Application —— 知识密度是终局壁垒

价值最终被「兑现」的一层。从功能型 SaaS 走向结果型 Agentic SaaS，软件加速「去 UI 化」。

| 护城河 · 如何守住 | 产业分工 · 如何协作 |
| --- | --- |
| 行业 Know-How / SOP：行业知识密度最难复制 | 向下接 Agent / 模型 / 数据，聚焦「最后一公里」 |
| 工作流嵌入 + 数据闭环：深嵌流程 + 独占场景数据成飞轮 | 计费从席位 → 结果 / 算力，重构商业模式 |
| 结果交付与 ROI 证明：稳定交付可量化结果即锁客 | 与 Agent 层分工：供领域工具 + SOP，享自主执行 |
| 可被调用性：能被 Agent 调用 / 编排成为新维度 | 向数据层回流场景数据，强化行业语义 |

> **本质**：模型达标只是入场券，行业 Know-How 沉淀与结果交付才是胜负手。

## 四、产业分工：六层如何协作闭环

每一层都在解决「上层能力如何高效供给、下层价值如何有效承接」。Token 是贯穿全链的量纲。

```
能源 ──供电──▶ 算力 ──供算──▶ 模型 ──供智──▶ 数据 ──供料──▶ Agent ──编排──▶ 应用
                                                                              │
                                                              回流场景数据闭环 ◀┘
```

| 层 | 角色 | 在闭环中的职责 |
| --- | --- | --- |
| 能源 | 供电 | GW 级稳定零碳电，决定算力产能上限 |
| 算力 | 供算 | 把电变成可消费算力，软件栈耦合模型 |
| 模型 | 供智 | 把算力变通用智能，打包为 Agent 底座 |
| 数据 | 供料 | 供带语义可信燃料，喂养模型与 Agent |
| Agent | 编排 | 调度模型 / 数据 / 工具，自主完成任务 |
| 应用 | 兑现 | 在场景中交付 ROI，回流数据闭环 |

> **跨层规律**：价值自下而上「变薄」、自上而下「变近」；Agent 层是重新分配价值的枢纽。

## 五、关键判断：2028 产业格局六条推演

1. **底层守 · 上层拓**：能源 / 算力 / 模型靠物理与生态壁垒守城；数据 / Agent / 应用靠场景与知识密度拓土。
2. **护城河整体上移**：通用能力商品化，价值从「造模型」向「懂行业 + 控入口」迁移。
3. **Token 成统一量纲**：全产业计费向 Token / 结果收敛，成本自下而上层层传导。
4. **整合与分工并存**：巨头追求全栈垂直整合，创业公司在 Agent / 应用层差异化突围。
5. **Agent 是价值战场**：协议标准（MCP / A2A）与入口归属，决定 2028 的产业话语权。
6. **知识密度定终局**：模型达标是入场券，行业 Know-How 与结果交付才是最终胜负手。

> —— 守城靠壁垒，拓土靠分工。
