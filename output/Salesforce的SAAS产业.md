# Salesforce 的 SaaS 策略

> **AI 产业六层模型 · 应用层 APPLICATION**
> 从 CRM 龙头到 Agentforce、Data Cloud 的智能化重构。
> 应用层是价值最终被兑现的一层——从「按席位卖软件」走向「按结果卖能力」。

## 01 公司定位：CRM 龙头到「客户全景 + Agent」

全球 CRM 市场领导者，以 Customer 360 整合销售、服务、营销，正向「Agent 驱动的应用」演进。

| 维度 | 关键点 | 说明 |
| --- | --- | --- |
| 基本盘 | CRM 第一 | 销售/服务/营销云构成的客户关系管理龙头 |
| 整合层 | Customer 360 | 统一客户全景数据与业务能力中台 |
| 数据层 | Data Cloud | 实时客户数据平台，喂养 AI 与 Agent |
| 智能层 | Agentforce | 面向业务场景的自主 Agent 平台 |

---

## 02 商业模式：从「按席位订阅」到「按结果计费」

传统 SaaS 按用户席位订阅；Agent 自动办事后，Salesforce 以 Agentforce 探索按对话/按结果计费。

| 传统模式 | 新模式 |
| --- | --- |
| 按席位（per seat）订阅收费 | Agentforce 按对话/按完成结果计费 |
| 收入与「使用软件的人数」绑定 | 收入与「办成的业务量」绑定 |
| 扩张靠加坐席、加模块 | Agent 替代人工操作，突破席位天花板 |
| 价值锚定在「人用界面的效率」 | 价值锚定在「交付的业务结果」 |

> **本质**：当 Agent 替人办事，计费基准从「有多少人在用」转向「办成了多少事」——定价逻辑被重构。

---

## 03 AI 重构：Agentforce 与 Data Cloud

Salesforce 的 AI 战略是「可信数据 + 自主 Agent」：让 Agent 基于企业自有数据安全地办事。

- **Data Cloud · 数据底座**：统一实时客户数据，为 Agent 提供可信上下文。
- **Agentforce · 自主 Agent**：在销售/服务等场景自动完成任务流。
- **Einstein · AI 能力层**：预测/生成式 AI 嵌入业务流程。
- **Trust Layer · 信任护栏**：权限、合规、审计，保障 Agent 可控可信。

---

## 04 产业护城河：数据 + 生态 + 切换成本

1. **数据护城河**：沉淀多年的客户关系数据 + Data Cloud，是 Agent 办事的独有上下文。
2. **生态护城河**：AppExchange 应用市场 + 庞大 ISV/咨询伙伴网络，形成平台引力。
3. **切换成本护城河**：深度嵌入企业核心业务流程与组织习惯，替换成本极高、客户留存强。

---

## 05 产业分工：站在云之上，整合模型，连接生态

Salesforce 处于价值链最上层，向下依赖云与模型，向外依靠生态，把能力兑现为业务结果。

| 方向 | 角色 | 说明 |
| --- | --- | --- |
| 向下 · 基础设施 | 依赖超大规模云 | 底层算力/存储运行在超大规模云之上 |
| 向下 · 模型 | 整合多家模型 | 通过 Einstein/Agentforce 接入 OpenAI、Anthropic 等 |
| 向外 · 生态 | AppExchange | ISV、咨询伙伴在平台上扩展场景 |
| 向上 · 客户 | 交付业务结果 | 面向企业业务部门，兑现可量化 ROI |

---

## 06 挑战与判断：去 UI 化与「被中介化」风险

当 Agent 成为新入口，应用层最大的风险是沦为「被调用的后端」，失去与用户的直接触点。

| 风险与挑战 | 应对与判断 |
| --- | --- |
| 平台级 Agent 中介化，抢走用户入口 | 用 Agentforce 主动成为「能力供给方」 |
| 去 UI 化削弱界面/体验差异 | 以独有数据 + 业务结果筑壁垒 |
| 能力被比价，沦为可替换的调用后端 | 把能力 API 化，进入各类 Agent 工作流 |
| 模型与数据平台向上挤压应用层 | Trust Layer 把「可信」做成差异点 |
| 按结果计费冲击传统席位收入 | 向「结果型 Agentic SaaS」转型 |

---

## 关键判断（Strategic Takeaways）

1. **从席位到结果**：Agent 替人办事，使计费从「按人」转向「按完成的业务结果」。
2. **数据是新护城河**：界面可复刻、能力会被比价，独有客户数据与可靠执行才是壁垒。
3. **主动拥抱去 UI 化**：与其被平台 Agent 中介化，不如主动成为被调用的能力供给方。

---

> **结语**：从卖软件，到卖办成的结果。当软件去 UI 化、Agent 成为入口，Salesforce 用数据 + 生态 + 可信执行，守住应用层的价值兑现权。
