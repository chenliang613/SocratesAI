## 01 背景判断：AI 时代，电力成为算力的硬约束

训练与推理的本质，是把电力转化为智能；当芯片不再是唯一瓶颈，电力与散热成为新的天花板。

| 维度 | 关键点 | 说明 |
| --- | --- | --- |
| 能耗激增 | 单园区 GW 级 | 超大规模 AI 数据中心单体功率迈向吉瓦级，逼近区域电网上限 |
| 供给紧张 | 电网排队 | 并网周期长、变电容量不足，电力可得性决定建站速度 |
| 成本结构 | 电费即成本 | 电价直接影响单位算力成本与云毛利，能效成为竞争力 |
| 可持续压力 | 碳中和承诺 | 气候承诺与监管要求绿电占比，倒逼能源结构升级 |

---

## 02 策略全景：AWS 的能源策略 = 三条主线 + 一个底座

亚马逊是全球最大的企业级可再生能源采购方之一，并以《气候承诺》锚定 2040 净零目标。

- **主线一 · 绿电规模采购**：以长期购电协议（PPA）大规模锁定风电、光伏，构筑全球最大企业绿电组合。
- **主线二 · 核电与新核能**：绑定核电数据中心、投资小型模块化反应堆（SMR），追求 7×24 稳定零碳电力。
- **主线三 · 能效自研**：自研 Trainium/Inferentia 芯片 + 定制供电与液冷，持续压低 PUE 与单位算力能耗。
- **底座 · 选址与自建电力**：围绕电力与气候选址，自建/直连电源，把能源纳入基础设施自主可控范围。

## 03 商业模式：能源如何服务于云的规模与毛利

能源对 AWS 不是成本中心，而是云业务规模与利润的杠杆——越早锁定廉价稳定的电，越能扩张产能、压低价格。

| 能源 → 产能 → 营收 | 垂直整合 → 毛利 |
| --- | --- |
| 电力可得性决定数据中心能建多少、建多快 | 自研芯片 + 定制供电 + 液冷，全栈压成本 |
| 锁定低价长协电，扩大可售算力供给上限 | 能效优势转化为更低单位算力价格或更高毛利 |
| 稳定零碳电支撑高密度 AI 集群持续满载 | 把上游能源风险内部化，平滑电价波动 |
| 绿电资质成为赢得大客户与合规订单的前提 | 能源与基础设施自主，减少对外部供给依赖 |

> **本质**：AWS 把能源做成「可控的基础设施变量」，用规模采购 + 垂直整合，将电力转化为云的产能与价格竞争力。

---

## 04 产业护城河：四道能源壁垒

1. **规模采购壁垒**：全球最大级别的绿电组合 + 资本实力，长协价格与供给量是中小玩家无法复制的。
2. **供给锁定壁垒**：核电绑定 + SMR 投资 + 长期 PPA，提前锁定未来十年的稳定零碳电力。
3. **能效技术壁垒**：自研芯片 + 定制供电 + 液冷，持续领先的 PUE 与单位算力能耗形成成本剪刀差。
4. **选址与并网壁垒**：围绕电力/气候的全球选址与电网协同能力，决定 AI 产能的扩张速度。

---

## 05 风险与判断：约束、风险与机会

能源既是 AWS 的护城河，也是其最大的外部不确定性。

| 风险与约束 | 机会与判断 |
| --- | --- |
| 电网并网周期长，制约扩张节奏 | 能源即算力上游，先锁定者先赢产能 |
| 核电/SMR 落地周期长、监管不确定 | 零碳电力成为大客户合规刚需 |
| 绿电间歇性，需储能/核电补足基荷 | 能效自研持续放大单位算力成本优势 |
| 碳中和承诺与 AI 高耗能的内在张力 | 向「能源 + 算力一体化」基础设施演进 |
| 电价上行侵蚀云毛利 | 能源能力成为云竞争的新维度 |

---

## 关键判断（Strategic Takeaways）

1. **能源是 AI 新瓶颈**：竞争焦点从「有没有芯片」延伸到「有没有电」，能源决定算力产能上限。
2. **锁定即护城河**：AWS 以规模采购 + 核电绑定 + 能效自研，把能源做成难以复制的结构性优势。
3. **能源服务于云**：能源最终是为云的产能、价格与毛利服务的杠杆，而非孤立的 ESG 叙事。

---

> **结语**：锁定能源，就是锁定算力的未来。当电力成为 AI 的硬约束，能源策略不再是成本科目，而是 AWS 最深的产业护城河之一。
